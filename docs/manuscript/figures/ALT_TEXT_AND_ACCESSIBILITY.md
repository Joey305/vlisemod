## Accessibility review notes

- Several captured pages rely on small navigation text and dense tables, so final composite figures should enlarge labels or annotate key regions.
- Dark-themed screenshots such as PROTAC Builder and E3 Ligandalyzer may need contrast checks when printed.
- Long pages should not be used directly in manuscript figures; cropped panels improve legibility and reduce repeated content.
- Final figure composites should add clear panel labels such as `(A)` through `(E)` because the raw screenshots do not include manuscript labels.
