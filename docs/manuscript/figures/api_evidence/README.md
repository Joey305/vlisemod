# API Evidence Notes

The files in this folder are lightweight public endpoint captures used as reproducibility-oriented manuscript evidence.

- `warhead_api_health.json`
- `warhead_api_manifest.json`
- `warhead_api_examples.json`
- `vlisemod_healthz.txt`

These files were captured from public endpoints without credentials and without submitting jobs. They should be treated as small availability checks, not as evidence of long-term endpoint guarantees or full API benchmarking.
