Citation and attribution

If you use V-LiSEMOD in research, presentations, or collaborative analysis, please cite the project and any related publications that informed the scientific framing.

Project description

V-LiSEMOD is a structure-guided viral ligand analysis platform focused on interaction review, solvent-exposed atoms, warhead/linkability evidence, PyMOL exports, and PROTACability-style triage.

Suggested software citation

Schulz, J.-M. V-LiSEMOD: Viral Ligand Solvent-Exposed Moiety Database for Structure-Guided Warhead Discovery and Degrader-Readiness Triage. Research software and web platform.

Related publication

Khurshid, Schulz, Hu, Snowden, Reynolds, and Schurer. Targeted degrader technologies as prospective SARS-CoV-2 therapies. Drug Discovery Today. 2024. DOI: 10.1016/j.drudis.2023.103847
