# How to cite V-LiSEMOD

Please cite the published Zenodo software release:

> The Schürer Lab. (2026). *V-LiSEMOD* (Version v2026.10) [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.23374625

The hosted [citation page](https://vlisemod.com/citation) provides this citation and an RIS download.

For a formal software citation, use the metadata in `CITATION.cff`.
